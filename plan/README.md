# Indeks Dokumen Rencana Sprint (`plan/`) — GuruDok

Folder `plan/` ini khusus menyimpan seluruh **Dokumen Perencanaan Sprint (Sprint Plans)** sebelum dieksekusi ke dalam folder [`todo/`](../todo/README.md) dan kode produksi.

---

## Alur Kerja (`plan/` $\rightarrow$ `todo/`)

1. **Instruksi Masuk:** Pengguna memberikan instruksi penambahan fitur atau perubahan.
2. **Baseline Verification:** Asisten melakukan verifikasi kondisi aktual kode, database, dan dataset (*Zero-Trust Audit*).
3. **Penulisan Plan:** Asisten menulis dokumen rencana di `plan/sprint-XX-<nama>.md` dengan status `WAITING_APPROVAL`.
4. **Approval Gate:** Setelah pengguna menyetujui (*Approve*) dokumen plan tersebut, barulah tugas-tugasnya dimasukkan ke folder [`todo/`](../todo/README.md) sebagai Sprint aktif dan dieksekusi dengan siklus **TDD (Red $\rightarrow$ Green $\rightarrow$ Refactor)**.
